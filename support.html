开始使用 / Getting started

Open the Korean reading sample / 打开韩文示例页 — no sign-in required.

1. Install the app and enable Korean X-Ray in Settings → Apps → Safari → Extensions (the Settings path can vary with iOS).

2. Open a Korean webpage in Safari. Open the page menu, select the extension, and allow access to that website.

3. Tap Annotate this page / 透视当前网页. Tap a marked word to inspect its entry. Use Restore original / 恢复原文 to remove annotations.

在 Safari 扩展设置中启用「韩语透视器」，再从 Safari 页面菜单打开扩展并允许访问当前网站，即可透视网页。也可开启自动透视、筛选词汇等级、隐藏已学会词。未标注的词可能是固有词、词典未收录的词，或上下文证据不足。

한국어 페이지를 열고 Safari 페이지 메뉴에서 확장 프로그램을 실행하세요. 웹사이트 접근을 허용한 뒤 주석을 적용할 수 있습니다.

Safariで拡張機能を有効にし、韓国語のページのメニューから起動してください。サイトへのアクセス許可が必要です。

在 Safari 擴充功能設定中啟用「韓語透視器」，從頁面選單開啟並允許存取目前網站，即可加入詞源標註。

Troubleshooting

- If a newly allowed page does not connect, reload the webpage and reopen the extension.

- Safari internal pages, editable fields, code blocks, hidden content, and some dynamically rendered pages cannot be annotated.

- If morphology initialization is unavailable, the extension uses a conservative fallback. Disabling and re-enabling annotations does not download a remote model.

- Ambiguous words can have more than one origin. Review the candidates instead of treating every annotation as a definitive translation.

- Learned words and corrections are stored locally. Export corrections before clearing app or extension data.

Contact / 反馈
